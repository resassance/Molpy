## О проекте

Molpy строится вокруг музыкальной записи: название, исполнители, релиз, обложка и версия трека. Ответы источников преобразуются в общую модель `Track`, чтобы интерфейс не зависел от структуры YouTube API.

Первый этап — Android. Затем планируются Windows и Linux, позднее рассматривается web. iOS в текущие планы не входит. Приложение для desktop и браузера пока не выпущено.

Собственный аккаунт Molpy и сервер не требуются. Вход в Google не реализован. Проект независим от YouTube, Google и поставщиков текстов; обход DRM и платного доступа не предусмотрен.

## Что реализовано

| Возможность | Что доступно |
| --- | --- |
| Поиск | Общая выдача и фильтры по трекам, артистам, альбомам и плейлистам; переходы к исполнителям и релизам; запасной поиск по YouTube |
| Публичные плейлисты | Прослушивание с любой песни или запуск со случайного трека, фоновая догрузка очереди и продолжение после перезапуска |
| Плеер | Воспроизведение, пауза, перемотка, следующий и предыдущий трек, позиция, длительность и буфер загрузки |
| Громкость | Выравнивание онлайн и офлайн по данным источника; отключается в настройках |
| Очередь | Добавление следующим или в конец, перемешивание, ручная перестановка и возврат по истории переходов; сохранение между запусками |
| Медиатека | Избранное, локальные плейлисты, альбомы и артисты; запуск коллекций вперемешку, загрузки в отдельном разделе |
| Профиль | Общее время прослушивания, любимые треки и артисты по времени звучания, история |
| Исполнители | Правка состава трека, выбор профиля YouTube Music, объединение дублей и отмена объединения |
| Оформление | Тёмный интерфейс с цветами обложек, компактными шапками коллекций и мини-плеером; большой плеер с соседними обложками и строкой текста песни |
| Фоновое воспроизведение | Media session и системные элементы управления Android |
| Тексты | YouTube Music и LRCLIB; текущая строка в плеере и полный текст, если он доступен для записи |
| Сеть | Системное соединение, HTTP CONNECT proxy без авторизации или с логином и паролем, SOCKS5 без авторизации |
| Загрузки | Скачивание по одному треку, пауза и продолжение, удаление, объём занятого места и локальное воспроизведение |

Правка исполнителей относится к одному треку. Объединение карточек — отдельное действие в меню артиста; его можно отменить.

После перезапуска очередь восстанавливается на паузе. Для продолжения нажмите Play. В публичных плейлистах перемешивание включается после получения полного списка записей; текущая песня продолжает играть. Ошибки загрузки текстов и обложек не прерывают аудио.

## Ограничения и планы

- **Доступ к YouTube:** если сервис недоступен в вашей сети, используйте системный VPN или настройте proxy в Molpy. Изменения на стороне YouTube могут влиять на поиск и воспроизведение.
- **Офлайн:** загрузки сохраняются внутри приложения. Удаление Molpy или очистка его данных удаляет скачанную музыку. Экспорт в общую папку Music пока не предусмотрен.
- **Форматы:** для скачивания используется один цельный аудиопоток без перекодирования; HLS и DASH для офлайна не поддерживаются. Совместимость зависит от формата записи и кодеков Android.
- **Фоновая загрузка:** Android может приостановить её из-за системных ограничений. После принудительной остановки приложения продолжение требует его открытия.

Windows и Linux планируются после Android, web — позже. Аккаунты, облачная синхронизация и интеграции с другими музыкальными сервисами пока не входят в ближайшие планы.

## Установка и первый запуск

**Требования:** Android 6.0 / API 23 или новее, 64-битное устройство `arm64-v8a` либо эмулятор/устройство `x86_64`. 32-битные ABI не включены в APK.

1. Откройте [релиз v0.1.0-alpha.13](https://github.com/resassance/Molpy/releases/tag/v0.1.0-alpha.13) и скачайте `Molpy-v0.1.0-alpha.13-debug.apk`.
2. Установите APK, разрешив установку из выбранного источника в настройках Android, если система запросит это.
3. Если YouTube в вашей сети недоступен, включите системный VPN или задайте proxy в настройках сети Molpy.
4. Найдите запись по исполнителю и названию и выберите её в результатах поиска.
5. Управляйте воспроизведением из плеера, откройте доступный текст песни или добавьте запись в избранное. Скачанные треки можно слушать без сети.

## Сборка из исходников

Нужны:

- JDK 17, доступный через `JAVA_HOME`;
- Android SDK Platform **37** и Build Tools **36.0.0**;
- путь к Android SDK через `ANDROID_HOME` или `sdk.dir` в локальном `local.properties`;
- сетевой доступ к Gradle distributions, Google Maven, Maven Central, Gradle Plugin Portal и JitPack для получения инструментов и зависимостей.

Версии библиотек закреплены в [version catalog](gradle/libs.versions.toml); Gradle Wrapper включён в репозиторий.

```sh
git clone https://github.com/resassance/Molpy.git
cd Molpy
./gradlew :androidApp:assembleDebug
```

В Windows используйте Gradle Wrapper для Windows:

```powershell
.\gradlew.bat :androidApp:assembleDebug
```

Готовый локальный APK: `androidApp/build/outputs/apk/debug/androidApp-debug.apk`.

## Архитектура и стек

| Модуль | Ответственность |
| --- | --- |
| [`core`](core) | Модели, идентичность треков, контракты источников, поиск и сопоставление, координация воспроизведения, очередь и правила загрузок |
| [`shared`](shared) | Адаптеры каталога, resolver и текстов, HTTP, Room-хранилище, обложки и Compose UI |
| [`androidApp`](androidApp) | Android entry point, Media3 engine, media session, фоновые загрузки и файловое хранилище |

Идентичность и происхождение записи отделены от идентификатора воспроизведения. Подписанный URL потока — временное значение в памяти процесса, а не постоянный идентификатор трека или сохраняемая ссылка.

| Назначение | Технология |
| --- | --- |
| Общая логика и UI | Kotlin 2.4.21, Compose Multiplatform 1.12.2, coroutines и Flow |
| Каталог и resolver | InnerTubeX 0.10.0 |
| HTTP | Ktor 3.6.0 с OkHttp; Media3 OkHttp data source |
| Android-аудио | Media3 1.11.1 |
| Обложки | Coil 3.6.3 |
| Тексты | YouTube Music и [LRCLIB](https://lrclib.net/) |
| Постоянные данные | Room 2.8.5 / SQLite 2.7.1: медиатека, очередь, история, настройки и метаданные |

## Участие в разработке

Ошибки и предложения принимаются через [GitHub Issues](https://github.com/resassance/Molpy/issues). Для ошибки укажите:

- версию релиза, модель устройства, Android/API и ABI;
- режим сети, использование VPN или proxy, без их реквизитов;
- шаги, ожидаемый и фактический результат, отображённый код ошибки;
- при необходимости — запрос, исполнителя, название, версию записи и стабильный ID источника.

Не публикуйте токены, cookies, пароли proxy/VPN, подписанные media URL и сырые ответы источников. Для диагностики не нужны копии аудио или полные тексты песен.

В pull request опишите изменение и задачу, которую оно решает.
