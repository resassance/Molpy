# Milestone 3 — Offline Implementation Plan

**Goal:** Явно скачанные выбранные треки полностью играют и перематываются после restart в airplane mode; неполные данные никогда не объявляются готовыми.

**Architecture:** Core определяет identity/completeness/resume policies; Android Media3 владеет transfer state и persistent download cache; Room связывает assets с библиотекой. Offline player не имеет сетевого upstream.

**Tech Stack:** [Основной план](2026-10-17-android-mvp.md), [одобренный spec](../specs/2026-10-17-music-player-design.md), разделы 8–9, 12–18.

Предусловие — [milestone 2](2026-10-17-02-state-network.md). Все Global Constraints/Review Focus сохраняются. Один concurrent download, стандартное качество, app-managed storage, без экспорта/конвертации.
